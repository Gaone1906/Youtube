Privacy Policy

Last updated: 30 October 2026

Pranav YT Uploader is a private tool operated by its single owner for their own YouTube channels and Google Drive. It has no other users.

Data accessed

With the owner's consent through Google OAuth, the tool uses the YouTube Data API, YouTube Analytics API and Google Drive API to upload and edit videos, captions, thumbnails and playlists on the owner's channels; read channel and video statistics; read and reply to comments on the owner's videos; and create and manage files the tool itself created in the owner's Google Drive.

Storage and sharing

OAuth tokens are stored privately by the owner and are never shared or sold. Data read from Google APIs is used only to produce reports for the owner and is not shared with third parties.

YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings.
